# Changelog — srd51-creatures-it

The Italian translation of srd51-creatures, from the official Italian System
Reference Document 5.1 by Wizards of the Coast (CC BY 4.0). The application
loads it by itself with the creatures when the interface is in Italian.
Like every public package, each released version is published by the site
and never changes (DEC-21).

## 0.1.0 — 2026-09-26

- **The 322 creatures of the SRD in Italian**: names, traits, actions,
  reactions and legendary actions as the Italian SRD writes them, with
  distances in metres.
