# Changelog — fan-heroes-it

The Italian translation of fan-heroes (DEC-27). The application loads it by itself when the interface is in
Italian. Like every public package, each released version is published by the site and never changes (DEC-21).

## 0.1.0 — 2026-11-10

- The twelve heroes in Italian, with the official Italian names of their works ("Ken il guerriero", "Frozen - Il
  regno di ghiaccio") and of the rules they use ("Palmo Tremante", "Cavaliere Mistico").
