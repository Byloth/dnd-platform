# srd51-excerpt — fixture package

An excerpt of the SRD 5.1 in content format v0 (`docs/phase-0/02-content-format.md`),
used as a fixture for the schemas, the validator and the engine. It is **not** the base
package (`packages/content/srd51`), which will hold the complete SRD.

Covers: the ruleset, the proficiency and spell-slot tables, the Monk (levels 1–3 only),
the Dwarf with the Hill Dwarf subspecies, the Acolyte background, the Grappler feat, ten
spells (darkness, darkvision, pass without trace, silence, minor illusion, fireball,
cure wounds, shield, bless, haste) with two spell lists, the fifteen standard conditions,
a few mundane items, the ten basic actions as rules, and one newcomer archetype.

Text is SRD 5.1 material (CC-BY-4.0, attribution in `package.yaml`); the mechanical
effects are authored by this project. Files are generated once by a script and then
maintained by hand.
